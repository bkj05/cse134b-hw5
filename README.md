## Between sets

Visitors can take a joke break on [Beyond Coding](https://bkj05.github.io/cse134b-hw5/beyond-coding.html#practice-break). Clicking **Get a guest joke** requests a random joke from the icanhazdadjoke API. While it loads, the current joke stays visible. On success, the component replaces the paragraph text with the new joke and announces that it loaded. If the request fails, the current joke stays and the visitor can select **Retry guest joke** without reloading the page.
